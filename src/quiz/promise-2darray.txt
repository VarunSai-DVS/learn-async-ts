    When the code has a setTimeout in its promise the flow of execution is different to that of the fetch() example.
    The setTimeout code is printed last and other log messages (in the promise) are printed before that.
    So the order of priority is Sync code -> promise code -> setTimeout.

    When the code does not have a setTimeout in the promise, the order of execution is the same which is
    sync code -> promise output
